# 概要设计 - GrepLogViewer

## 1. 项目概述
GrepLogViewer 是一个 VS Code 插件，基于正则表达式提供文本文件的增强查看体验。核心思路：为每个编辑器标签页附加一个配置面板，用户配置正则表达式组和匹配规则，满足条件的行高亮显示，不满足的自动折叠。

## 2. 系统架构

### 2.1 整体分层（MVC）

```
┌─────────────────────────────────────────┐
│              View Layer                 │
│  - ConfigPanel (Webview Panel)          │
│  - EditorDecorations (行高亮/折叠)       │
├─────────────────────────────────────────┤
│           Controller Layer              │
│  - ConfigController    配置管理          │
│  - FilterController    过滤/匹配控制     │
│  - ViewController      视图协调          │
├─────────────────────────────────────────┤
│            Model Layer                  │
│  - RegexGroupModel    正则组数据模型      │
│  - EditorStateModel   编辑器状态模型      │
│  - FilterResultModel  过滤结果模型        │
└─────────────────────────────────────────┘
```

### 2.2 组件关系

```
Extension Entry (activate)
    │
    ├── ViewController ── 管理每个编辑器的 Webview Panel + Decoration
    │       │
    │       ├── ConfigPanel (View) ── 正则组配置 UI
    │       │       │
    │       │       └── ConfigController ── 增删改正则组
    │       │               │
    │       │               └── RegexGroupModel
    │       │
    │       └── EditorDecorations (View) ── 行高亮/折叠
    │               │
    │               └── FilterController ── 正则匹配计算
    │                       │
    │                       ├── FilterResultModel
    │                       └── RegexGroupModel
    │
    └── EditorStateModel ── 跟踪每个编辑器状态
```

## 3. 核心数据流

### 3.1 配置 → 生效流程
```
用户编辑配置 → ConfigPanel → ConfigController → RegexGroupModel 存储
     │
     ▼ (用户点击 "Go")
FilterController 读取 RegexGroupModel
     │
     ▼
遍历编辑器每一行，对每组正则按 AND/OR/NOT 逻辑匹配
     │
     ▼
首组匹配的行标记为该组颜色，后续组跳过已匹配行
     │
     ▼
FilterResultModel 存储结果 → EditorDecorations 高亮/折叠
```

### 3.2 正则组匹配算法（首次匹配优先）
```
对每个正则组（按配置顺序）:
    对尚未匹配的每一行:
        按 AND/OR/NOT 组合逻辑判定
        若该行满足 → 标记此行的 groupId 和 color
        将该行加入"已匹配集合"
未匹配到的行 → 折叠
```

## 4. 模块划分

| 模块 | 职责 | 所属层 |
|------|------|--------|
| RegexGroupModel | 正则组数据结构，序列化/反序列化 | Model |
| EditorStateModel | 编辑器-配置绑定关系，状态管理 | Model |
| FilterResultModel | 匹配结果、行颜色映射 | Model |
| ConfigController | 正则组的增删改操作 | Controller |
| FilterController | 正则匹配引擎，首组匹配算法 | Controller |
| ViewController | Webview 生命周期，编辑器事件协调 | Controller |
| ConfigPanel | Webview 配置界面 | View |
| EditorDecorations | 行装饰（高亮颜色、折叠） | View |

## 5. 技术选型
- **语言**: TypeScript
- **Webview**: VS Code Webview API（HTML/CSS/原生JS，不引入框架以减少复杂度）
- **存储**: VS Code workspaceState（工作区级别持久化配置）
- **正则引擎**: JavaScript 原生 RegExp
- **折叠**: VS Code foldingRangeProvider 或 decoration 隐藏
