# 原型设计 - GrepLogViewer

## 1. 插件入口

### 1.1 侧边栏面板
- 配置面板位于 VS Code 左侧边栏 Explorer 下方，名称 `GrepLogViewer`
- 通过 `registerWebviewViewProvider` 注册，不抢占编辑器焦点
- `onView:greplogviewer.configView` 激活事件

## 2. 配置面板原型

### 2.1 面板位置
左侧边栏 Explorer 下方的固定 WebviewView。

### 2.2 面板布局（侧边栏）

```
┌──────────────────────────────┐
│ LINE RANGE                   │
│ From: [___]  To: [___]       │
│ leave empty for all          │
├──────────────────────────────┤
│ PATTERN GROUPS               │
│ ┌──────────────────────────┐ │
│ │ Group Name          [×]  │ │
│ │ Color [██]               │ │
│ │ Expr [/ERROR/] [i]  [×]  │ │
│ │ AND [/timeout/]     [×]  │ │
│ │ + Expr                   │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ Warnings            [×]  │ │
│ │ Color [██] #FFAA00       │ │
│ │ Expr [/WARN/] [i]   [×]  │ │
│ │ + Expr                   │ │
│ └──────────────────────────┘ │
│ + Add Group                  │
├──────────────────────────────┤
│   [Go]  [Clear]  [Reset]     │
└──────────────────────────────┘
```

### 2.3 交互细节

1. **行范围**: 可选的 From/To 行号输入，留空表示全文匹配
2. **正则组**: 增删改组名和颜色，组内增删表达式，操作符 AND/OR/NOT 切换
3. **Go 按钮**: 收集配置 → 执行过滤 → 高亮匹配行 + 折叠未匹配行
4. **Clear 按钮**: 清除高亮和折叠，保留配置
5. **Reset 按钮**: 清除所有配置和效果

## 3. 编辑器显示效果

### 3.1 未激活状态（默认）
编辑器正常显示所有内容，无折叠，无颜色高亮。

### 3.2 激活状态（Go 后）

```
文件内容:                         显示效果:
┌──────────────────────────┐     ┌──────────────────────────┐
│ 2024-01-01 INFO started  │     │ [collapsed region]       │  ← 未匹配，折叠
│ 2024-01-01 DEBUG config  │     ├──────────────────────────┤
│ 2024-01-01 ERROR timeout │     │ 2024-01-01 ERROR timeout │  ← 红色 (#FF4444)
│ 2024-01-01 INFO retry    │     │ [collapsed region]       │  ← 未匹配，折叠
│ 2024-01-01 WARN memory   │     │ 2024-01-01 WARN memory   │  ← 橙色 (#FFAA00)
│ 2024-01-01 INFO done     │     │ [collapsed region]       │  ← 未匹配，折叠
└──────────────────────────┘     └──────────────────────────┘
```

**颜色渲染**: 使用 `vscode.TextEditor.setDecorations()` 配合 `createTextEditorDecorationType({ color, fontWeight: 'bold' })` 设置匹配行颜色，未匹配行用 `opacity: 0.3` 灰暗。

**折叠实现**: 使用 `createFoldingRangeFromSelection` 创建手动折叠（Go），`editor.removeManualFoldingRanges` 清除（Clear/Reset/打开文件）。

## 4. 状态流转

```
          打开编辑器
              │
              ▼
    ┌─────────────────┐
    │  未激活状态       │ ← 配置面板显示，无过滤效果
    │  (所有行可见)     │
    └────┬────────────┘
         │ 点击 Go
         ▼
    ┌─────────────────┐
    │  过滤激活状态     │ ← 匹配行高亮，未匹配行折叠
    └────┬────────────┘
         │ 点击 Clear → 回未激活（保留配置）
         │ 点击 Reset → 回未激活（清除配置）
         │ 切换编辑器再切回 → 恢复高亮（isActive=内存状态）
         │ 重启 VS Code → 未激活（isActive 不持久化）
```
