# 原型设计 - GrepLogViewer

## 1. 插件入口

### 1.1 命令面板
- 命令: `GrepLogViewer: Show Config Panel` (`greplogviewer.showConfig`)
- 快捷键: 可自定义，默认无绑定
- 打开方式: 命令面板（Cmd/Ctrl+Shift+P）或编辑器标题栏按钮

### 1.2 编辑器标题栏按钮
在编辑器右上角添加图标按钮，点击切换配置面板显示/隐藏。

## 2. 配置面板原型

### 2.1 面板位置
位于编辑器右侧的 Webview Panel（通过 `vscode.window.createWebviewPanel` 或 `ViewColumn.Beside` 放置在编辑器旁边）。

### 2.2 面板布局（详细）

### 2.3 交互细节

1. **添加组**: 点击 [+ 添加组]，创建默认名称和随机颜色的新组
2. **删除组**: 点击组标题右侧 [×]，弹出确认后删除
3. **修改组名**: 点击组名变为输入框，支持编辑
4. **修改颜色**: 点击颜色块弹出颜色选择器（HTML `<input type="color">`）
5. **添加表达式**: 点击 [+ 添加表达式]，弹出新行，含操作符下拉、正则输入框、flags输入框
6. **删除表达式**: 点击表达式行右侧 [×]
7. **操作符选择**: 下拉选择 AND / OR / NOT（首表达式无操作符）
8. **Go 按钮**: 
   - 收集所有配置
   - 校验所有正则表达式合法性
   - 非法表达式高亮提示错误
   - 全部合法则发送消息给 Extension
9. **Reset 按钮**: 清除所有配置和编辑器显示效果

## 3. 编辑器显示效果

### 3.1 未激活状态（默认）
编辑器正常显示所有内容，无折叠，无颜色高亮。

### 3.2 激活状态（Go 后）

```
文件内容:                         显示效果:
┌──────────────────────────┐     ┌──────────────────────────┐
│ 2024-01-01 INFO started  │     │ [collapsed region]       │  ← 未匹配，折叠
│ 2024-01-01 DEBUG config  │     ├──────────────────────────┤
│ 2024-01-01 ERROR timeout │     │ 2024-01-01 ERROR timeout │  ← 红色 (#FF4444)
│ 2024-01-01 INFO retry    │     │ [collapsed region]       │  ← 未匹配，折叠
│ 2024-01-01 WARN memory   │     │ 2024-01-01 WARN memory   │  ← 橙色 (#FFAA00)
│ 2024-01-01 INFO done     │     │ [collapsed region]       │  ← 未匹配，折叠
└──────────────────────────┘     └──────────────────────────┘
```

**颜色渲染**: 使用 `vscode.TextEditor.setDecorations()` 配合 `createTextEditorDecorationType({ color: '#FF4444' })` 设置匹配行的文字颜色。

**折叠实现**: 使用 `vscode.languages.registerFoldingRangeProvider` 或通过 `vscode.commands.executeCommand('editor.fold')` 对连续的未匹配行进行折叠。如果 decoration API 的 `opacity` 或 `textDecoration` 支持（实际不支持隐藏行），备选方案是计算未匹配行的连续区间，通过 folding range 方式折叠。

**说明**: 如折叠方案受限，可退化为仅颜色高亮 + 降低未匹配行透明度（通过 decoration 的 `opacity` 属性）。

## 4. 状态流转

```
          打开编辑器
              │
              ▼
    ┌─────────────────┐
    │  未配置状态       │ ← 默认：无配置面板或面板已关闭
    │  (所有行可见)     │
    └────┬────────────┘
         │ 打开配置面板
         ▼
    ┌─────────────────┐
    │  配置编辑状态     │ ← 编辑正则组，未生效
    │  (所有行可见)     │
    └────┬────────────┘
         │ 点击 Go (配置合法)
         ▼
    ┌─────────────────┐
    │  过滤激活状态     │ ← 匹配行高亮，未匹配行折叠
    │  (过滤+高亮)      │
    └────┬────────────┘
         │ 点击 Reset / 清除配置
         ▼
    ┌─────────────────┐
    │  未配置状态       │ ← 恢复
    └─────────────────┘
```
