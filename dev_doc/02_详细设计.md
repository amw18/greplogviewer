# 详细设计 - GrepLogViewer

## 1. 数据模型设计

### 1.1 核心数据类型
```typescript
// 逻辑操作符枚举
enum LogicOperator {
  AND = 'and',
  OR = 'or',
  NOT = 'not'
}

// 单个正则表达式
interface RegexExpression {
  id: string;            // 唯一标识
  pattern: string;       // 正则表达式字符串
  flags: string;         // 正则标志 (g, i, m 等)
  operator: LogicOperator; // 与前一表达式的逻辑关系（首表达式此字段无意义）
}

// 正则组（包含颜色和多条表达式）
interface RegexGroup {
  id: string;            // 唯一标识，UUID
  name: string;          // 组名，便于识别
  color: string;         // 匹配行文本颜色（CSS颜色值）
  expressions: RegexExpression[];  // 该组下的正则表达式列表
}
```

**逻辑组合规则**: 组内表达式按顺序从左到右计算。首表达式直接判定匹配结果，后续表达式通过 operator 字段与当前累积结果组合（AND/OR/NOT）。

### 1.2 EditorState 与 FilterResult
```typescript
interface EditorState {
  editorId: string;          // 编辑器唯一标识
  documentUri: string;       // 文档 URI
  groups: RegexGroup[];      // 配置的正则组列表
  active: boolean;           // 是否已应用（Go 按钮按下后为 true）
}

interface FilterResult {
  lineNumber: number;        // 行号
  groupId: string | null;    // 匹配的正则组 ID，null 表示未匹配（将被折叠）
  color: string | undefined; // 显示颜色
}
```

## 2. 核心算法

### 2.1 单行匹配判定（对单个 RegexExpression）
```
function matchExpression(line: string, expr: RegexExpression): boolean
    regex = new RegExp(expr.pattern, expr.flags)
    return regex.test(line)
```

### 2.2 单组逻辑判定（表达式组合）
```
function matchGroup(line: string, group: RegexGroup): boolean
    result = matchExpression(line, group.expressions[0])
    for i = 1 to expressions.length - 1:
        expr = group.expressions[i]
        match = matchExpression(line, expr)
        if expr.operator == AND: result = result && match
        else if expr.operator == OR: result = result || match
        else if expr.operator == NOT: result = result && !match
    return result
```

### 2.3 全文过滤（首次匹配优先）
```
function filterDocument(lines: string[], groups: RegexGroup[]): FilterResult[]
    matchedLines = new Set<number>()
    results = []
    for group in groups (按配置顺序):
        for lineNum in [0..lines.length-1]:
            if lineNum in matchedLines: continue
            if matchGroup(lines[lineNum], group):
                results[lineNum] = { lineNumber: lineNum, groupId: group.id, color: group.color }
                matchedLines.add(lineNum)
    // 未匹配行标记为折叠
    for lineNum in [0..lines.length-1]:
        if lineNum not in matchedLines:
            results[lineNum] = { lineNumber: lineNum, groupId: null, color: undefined }
    return results
```

### 2.4 折叠实现策略
由于 VS Code 不支持直接隐藏行，采用以下组合方案：

**方案：FoldingRangeProvider + 主动折叠命令**
1. 在 `activate()` 中注册一个全局 `FoldingRangeProvider`，选择器覆盖常见文本文件类型
2. Provider 从 `FilterResultModel` 读取当前文档的过滤结果，将连续的未匹配行映射为 `FoldingRange[]` 返回
3. Go 按下后：FilterController 计算完成 → 调用 `vscode.commands.executeCommand('editor.fold', ...)` 对每个折叠区间主动执行折叠
4. 文档变更时：Provider 自动返回最新区间，VS Code 管理折叠状态

**兜底方案**：如折叠效果不理想，匹配行使用 `createTextEditorDecorationType({ color })` 设置颜色，未匹配行使用 `opacity: 0.3` 降低可见度

## 3. 配置持久化
- 使用 `context.workspaceState` 存储配置
- key 格式: `greplogviewer.config.{documentUri}`
- value: `RegexGroup[]`

## 4. 事件流程

### 4.1 插件激活
```
activate(context):
    注册命令: greplogviewer.showConfig
    监听: window.onDidChangeActiveTextEditor
    为当前编辑器创建/恢复配置面板
```

### 4.2 编辑器切换
```
onDidChangeActiveTextEditor(editor):
    销毁旧面板
    如果 editor 存在:
        加载该文档的持久化配置
        创建新 ConfigPanel
        创建新 EditorDecorations
```

### 4.3 Go 按钮按下
```
onGoClick():
    1. ConfigPanel 将当前配置发送给 ViewController
    2. ViewController 调用 ConfigController 保存配置
    3. FilterController 执行全文过滤
    4. EditorDecorations 应用高亮和折叠
    5. 持久化配置到 workspaceState
```

### 4.4 配置变更（增删改）
```
每次增删改操作 → ConfigPanel 本地维护状态
仅在 Go 按钮按下时 → 同步到 Controller → 触发生效
编辑过程中不影响编辑器显示（即配置不需要实时生效）
```

## 5. Webview 配置面板设计

### 5.1 布局
```
┌──────────────────────────────────────┐
│  Regex Group 1                 [×]   │
│  ┌─ Color: [■■■■] #FF0000 ─────────┐│
│  │  Expr1: [/pattern/] flags [i] [×]││
│  │  [AND ▼] Expr2: [/pattern/]  [×] ││
│  │  [+ Add Expression]              ││
│  └──────────────────────────────────┘│
├──────────────────────────────────────┤
│  Regex Group 2                 [×]   │
│  └─ ...                              │
├──────────────────────────────────────┤
│  [+ Add Group]                       │
├──────────────────────────────────────┤
│           [Go]  [Reset]              │
└──────────────────────────────────────┘
```

### 5.2 交互说明
- 每个组可以折叠/展开
- 组内表达式可增删，操作符可切换（AND/OR/NOT）
- 颜色选择：使用 HTML color input
- 拖拽调整组顺序（简单实现可选）
- Go 按钮：应用配置并生效
- Reset 按钮：清除所有配置并取消折叠/高亮
