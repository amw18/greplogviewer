# 详细设计 - GrepLogViewer

## 1. 数据模型设计

### 1.1 核心数据类型
```typescript
// 逻辑操作符枚举
enum LogicOperator {
  AND = 'and',
  OR = 'or',
  NOT = 'not'
}

// 单个正则表达式
interface RegexExpression {
  id: string;            // 唯一标识
  pattern: string;       // 正则表达式字符串
  flags: string;         // 正则标志 (g, i, m 等)
  operator: LogicOperator; // 与前一表达式的逻辑关系（首表达式此字段无意义）
}

// 正则组（包含颜色和多条表达式）
interface RegexGroup {
  id: string;            // 唯一标识，UUID
  name: string;          // 组名，便于识别
  color: string;         // 匹配行文本颜色（CSS颜色值）
  expressions: RegexExpression[];  // 该组下的正则表达式列表
}
```

**逻辑组合规则**: 组内表达式按顺序从左到右计算。首表达式直接判定匹配结果，后续表达式通过 operator 字段与当前累积结果组合（AND/OR/NOT）。

### 1.2 EditorState 与 FilterResult
```typescript
interface EditorState {
  editorId: string;          // 编辑器唯一标识
  documentUri: string;       // 文档 URI
  groups: RegexGroup[];      // 配置的正则组列表
  active: boolean;           // 是否已应用（Go 按钮按下后为 true）
}

interface FilterResult {
  lineNumber: number;        // 行号
  groupId: string | null;    // 匹配的正则组 ID，null 表示未匹配（将被折叠）
  color: string | undefined; // 显示颜色
}
```

## 2. 核心算法

### 2.1 单行匹配判定（对单个 RegexExpression）
```
function matchExpression(line: string, expr: RegexExpression): boolean
    regex = new RegExp(expr.pattern, expr.flags)
    return regex.test(line)
```

### 2.2 单组逻辑判定（表达式组合）
```
function matchGroup(line: string, group: RegexGroup): boolean
    result = matchExpression(line, group.expressions[0])
    for i = 1 to expressions.length - 1:
        expr = group.expressions[i]
        match = matchExpression(line, expr)
        if expr.operator == AND: result = result && match
        else if expr.operator == OR: result = result || match
        else if expr.operator == NOT: result = result && !match
    return result
```

### 2.3 全文过滤（首次匹配优先）
```
function filterDocument(lines: string[], groups: RegexGroup[]): FilterResult[]
    matchedLines = new Set<number>()
    results = []
    for group in groups (按配置顺序):
        for lineNum in [0..lines.length-1]:
            if lineNum in matchedLines: continue
            if matchGroup(lines[lineNum], group):
                results[lineNum] = { lineNumber: lineNum, groupId: group.id, color: group.color }
                matchedLines.add(lineNum)
    // 未匹配行标记为折叠
    for lineNum in [0..lines.length-1]:
        if lineNum not in matchedLines:
            results[lineNum] = { lineNumber: lineNum, groupId: null, color: undefined }
    return results
```

### 2.4 折叠实现策略（最终方案）

**不使用 FoldingRangeProvider**（该 API 产生的区间会被 VS Code 持久化，导致重新打开文件时自动恢复旧折叠）。

改用两个 VS Code 标准 API：
1. `editor.createFoldingRangeFromSelection` — 选中未匹配行区间，创建手动折叠（自动折叠）
2. `editor.removeManualFoldingRanges` — 选中全文，清除所有手动折叠（=`Ctrl+K Ctrl+,`）

**Go 流程**: unfoldAll → 逐区间 createFoldingRangeFromSelection
**Clear/Reset**: unfoldAll → 选中全文 → removeManualFoldingRanges
**打开文件时**: attach() 对非激活编辑器调用 removeManualFoldingRanges 清除残留

**颜色策略**: 匹配行用 `createTextEditorDecorationType({ color, fontWeight: 'bold' })`，未匹配行用 `opacity: 0.3`

## 3. 配置持久化
- 使用 `context.workspaceState` 存储配置
- key 格式: `greplogviewer.config.{documentUri}`
- value: `EditorConfig`（兼容旧格式 `RegexGroup[]`）

```typescript
interface EditorConfig {
  groups: RegexGroup[];
  startLine?: number;  // 开始行号(1-based)
  endLine?: number;    // 结束行号(1-based)
}
```

## 4. 事件流程

### 4.1 插件激活
```
activate(context):
    注册 WebviewViewProvider（侧边栏面板）
    监听: window.onDidChangeActiveTextEditor
    监听: workspace.onDidChangeTextDocument
    isActive 为内存状态，重启 VS Code 后全清空
```

### 4.2 编辑器切换
```
attach(editor):
    清除旧编辑器装饰
    加载该文档的持久化配置 (EditorConfig)
    if isActive:
        恢复颜色装饰（折叠由 VS Code 维护）
    else if 有旧配置:
        调用 removeManualFoldingRanges 清除折叠残留
    刷新侧边栏面板
```

### 4.3 Go 按钮按下
```
handleGo(groups, startLine, endLine):
    1. 保存配置到 RegexGroupModel + workspaceState
    2. 设置 isActive = true
    3. FilterController.filter(lines, groups, startLine, endLine)
    4. EditorDecorations.apply(results, editor)
    5. applyFolding: unfoldAll → createFoldingRangeFromSelection
```

### 4.4 Clear / Reset
```
Clear: 清除显示效果（高亮+折叠），保留配置，setActive(false)
Reset: 清除配置 + 显示效果，clearEditor
共用: unfoldAll → removeManualFoldingRanges
```

## 5. Webview 配置面板设计

### 5.1 布局
```
┌──────────────────────────────────┐
│ LINE RANGE                       │
│ From: [___]  To: [___]           │
│ leave empty for all              │
├──────────────────────────────────┤
│ PATTERN GROUPS                   │
│ ┌──────────────────────────────┐ │
│ │ Group Name              [×]  │ │
│ │ Color [██]                   │ │
│ │ Expr [/pattern/] [i]    [×]  │ │
│ │ AND [/pattern/]          [×] │ │
│ │ + Expr                       │ │
│ └──────────────────────────────┘ │
│ + Add Group                      │
├──────────────────────────────────┤
│      [Go] [Clear] [Reset]        │
└──────────────────────────────────┘
```

### 5.2 按钮说明
- **Go**: 应用过滤 + 折叠（仅对匹配范围内行过滤）
- **Clear**: 清除显示效果（高亮+折叠），保留配置
- **Reset**: 清除配置 + 显示效果，恢复初始状态
