# 原型设计 — GrepLogViewer v0.0.7

## UI 布局原型

### 整体面板布局（紧凑版）

```
┌─────────────────────────────────────┐
│ GrepLogViewer                        │
├─────────────────────────────────────┤
│ ▸ Line Ranges                       │  ← 默认折叠
├─────────────────────────────────────┤
│ ▸ Time Pattern [auto-detected]      │  ← 检测到格式时自动展开提示
├─────────────────────────────────────┤
│ Pattern Groups                      │
│ ┌─────────────────────────────────┐ │
│ │ ☑ [Error  ] [/ERROR/ ] [im] 🟥 ×│ │  ← 拖拽手柄隐式（整卡可拖）
│ │   ☑ AND [/timeout/   ] [s ]  × │ │
│ │   ☑ NOT [/ignore/    ] [  ]  × │ │  [+ Expr]│
│ ├─────────────────────────────────┤ │
│ │ ☑ [Warn   ] [/WARN / ] [i ] 🟧 ×│ │
│ ├─────────────────────────────────┤ │
│ │ ☑ [Info   ] [/INFO / ] [  ] 🟩 ×│ │
│ └─────────────────────────────────┘ │
│ [+ Add Group]                       │
├─────────────────────────────────────┤
│ Keyword Highlight                   │
│ ▲ Prev Group Match  ▼ Next Group Match│  ← 原 group 箭头改为匹配行导航
│ ┌─────────────────────────────────┐ │
│ │ ☑ [/error/  ] [im] 🟥 [err ][matched]▲▼×│  ← matchScope 选择器
│ │ ☑ [/warn/   ] [i ] 🟧 [warn][full   ]▲▼×│
│ └─────────────────────────────────┘ │
│ [+ Add Keyword]                     │
├─────────────────────────────────────┤
│ ▸ Config Management                 │  ← 折叠
├─────────────────────────────────────┤
│   [Go] [Clear] [Reset]     15/200  │
└─────────────────────────────────────┘
```

### Section 折叠交互

```
默认状态:
  ▸ Line Ranges                    ← 折叠，点击展开

点击后:
  ▾ Line Ranges                    ← 展开
  ┌ 行范围卡片 ... ┐
  [+ Add Range]

再次点击:
  ▸ Line Ranges                    ← 收起
```

### 拖拽交互

```
用户拖拽 Group Card:
  1. mousedown 在 group-card 上 → 整卡半透明
  2. 拖动经过其他 group-card → 目标位置显示蓝色插入线
  3. 释放 → group 重排，保存，重新渲染
```

### Match Scope 选择器

```
keyword 行末尾:
  [matched ▾]   ← 下拉选择

选项:
  matched  — 仅在已匹配行中匹配（默认新关键词）
  full     — 全文扫描（旧关键词兼容）
```

### 导航按钮

```
在 Keyword Highlight section 顶部:
  ┌─────────────────────────────────┐
  │ ▲ Prev Group Match              │  ← 跳转到上一个被 group 匹配的行
  │ ▼ Next Group Match              │  ← 跳转到下一个被 group 匹配的行
  └─────────────────────────────────┘
```
