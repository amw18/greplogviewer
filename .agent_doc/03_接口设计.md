# 接口设计 — GrepLogViewer v0.0.7

## 类型变更

### KeywordConfig 新增字段
```typescript
interface KeywordConfig {
  id: string;
  pattern: string;
  flags: string;
  color: string;
  enabled?: boolean;
  hint?: string;
  // 新增
  matchScope?: 'matched' | 'full';  // 默认 'full'（向后兼容旧数据）
}
```

### RegexGroup 删除字段
```typescript
interface RegexGroup {
  id: string;
  name: string;
  color: string;
  expressions: RegexExpression[];
  enabled?: boolean;
  // associatedDirs?: string;  ← 已删除
}
```

### Webview ↔ Extension 消息协议删除
```typescript
// 删除：
// SyncConfigMessage 中 groups 不再包含 associatedDirs（类型自动跟随 RegexGroup 变动）
```
