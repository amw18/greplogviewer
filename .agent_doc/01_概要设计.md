# 概要设计 — GrepLogViewer v0.0.7

## 变更概述
本次变更覆盖 7 个需求点，旨在优化用户体验、简化配置、减少面板占用空间。

## 需求映射

| # | 需求 | 变更类型 | 影响范围 |
|---|------|----------|----------|
| 1 | 修复 "View container 'panel' does not exist" 警告 | 修复 | package.json |
| 2 | 删除 dirs 配置和 add as dir 功能 | 删除 | types, GrepController, ViewController, ConfigPanel, extension, package.json |
| 3 | 减少面板宽度，+expr 同行显示 | 重构 UI | ConfigPanel |
| 4 | Line Ranges 默认折叠 | UI 增强 | ConfigPanel |
| 5 | 智能时间格式自动检测 | 新增功能 | TimeMatchModel, ConfigPanel, ViewController |
| 6 | 拖拽调整组顺序，箭头改为导航匹配行 | UI 增强 | ConfigPanel, ViewController |
| 7 | Keyword 匹配范围选择（组匹配行 vs 全文） | 新增功能 | types, FilterController, ViewController, EditorDecorations, ConfigPanel |

## 架构影响

### 删除的模块/接口
- `RegexGroup.associatedDirs` — 从类型定义和所有引用中移除
- `GrepController.getParsedDirs()` — 不再需要解析 dirs 配置
- `GrepController.getRawDirs()` — 不再从持久化配置读取 dirs
- `ViewController.addDirToGroup()` — 删除此方法
- `package.json` 中 `greplogviewer.addDirToGroup` 命令、菜单、激活事件
- `extension.ts` 中 `addDirToGroup` 命令注册

### 修改的模块
- `TimeMatchModel` — 新增 `autoDetect()` 方法，从日志行自动推断时间格式
- `FilterController.filter()` — 支持 keyword 的 `matchScope` 参数
- `ViewController.markKeywordVisibleLines()` — 适配 `matchScope: 'matched'`

### 新增的接口
- `KeywordConfig.matchScope` — `'matched' | 'full'`，控制 keyword 匹配范围
- `TimeMatchModel.autoDetect(lines: string[])` — 返回建议的 TimePatternConfig

## 数据流变更

### Grep Keyword/Function 简化后
```
用户右击 → GrepController.grepKeyword/grepFunction
  → 获取 workspace root 作为搜索路径
  → 执行 grep 命令
  （不再查找 associatedDirs 配置）
```

### Smart Time Pattern 流程
```
用户打开文件 → ViewController.attach()
  → TimeMatchModel.autoDetect(lines)
  → 若检测到格式 → 自动填充 timePattern 到面板
```

### Keyword 匹配范围
```
matchScope === 'matched' (默认):
  keyword 仅扫描已匹配行 → 速度快，结果精准

matchScope === 'full':
  keyword 扫描 [scanStart, scanEnd) 内所有行 → 全文搜索
```

## UI 布局变更

### 面板宽度缩减策略
1. Group header 行内联显示：checkbox + name + 首表达式 + flags + 颜色 + 操作按钮
2. "+ Expr" 按钮移到表达式 header 行右侧
3. 颜色选择器缩小为圆点
4. 复杂设置（Line Ranges, Time Pattern, Config Management）折叠为可展开 section

### 拖拽实现
- 使用 HTML5 Drag and Drop API
- group-card 设置 draggable="true"
- dragstart/dragover/drop 事件处理数组重排
- 视觉反馈：拖动时半透明 + 插入位置指示线

### 箭头按钮重新定位
- 原 ▲/▼ 从 group 顺序切换改为编辑器匹配行导航
- 新增按钮在 action-bar 区域：▲ Prev Match / ▼ Next Match
